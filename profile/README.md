# vArranger2 — live keyboard styles and backing band

vArranger2 keeps one named board on the desk: the live style, the backing groove in front of you, and a short note the next keyboard set can read. Extra styles wait for their own title.

## Session Card

| Slice | What you do in vArranger2 | What remains |
|-------|------------------------|--------------|
| Arrival | Open vArranger2 and name today's gig desk | A titled style set |
| Focus | Keep only the live style on the vArranger2 board | A short backing band |
| Check | Read vArranger2 arranger styles before a large groove change | A confirmed live keyboard |
| Handoff | Mark finished styles inside vArranger2 | A note for the next set |

## How vArranger2 Sits

vArranger2 does not replace the hardware arranger, the DAW, or the backing-track folder you already keep. It sits beside them as a named gig desk for one job: which arranger styles are live, which backing band still matches the keyboard, and what the next set should read.

A first visit should be one short style, then the same vArranger2 gig desk the next night. That is enough to see if the named style set holds.

## Traffic Light

| Signal | On the vArranger2 board | What you do |
|--------|----------------------|-------------|
| Green | Named gig desk, short live style list | Continue the same backing band |
| Amber | Two dances mixed in one style set | Split the groove before you play |
| Red | No title, no note, styles unlabeled | Stop and name the gig file first |

## Open Order

1. Open the last vArranger2 gig desk, not a new empty style set.
2. Read the backing band and the last handoff.
3. Finish one visible live keyboard pass inside vArranger2.
4. Write what changed, then close with fewer unlabeled styles than you found.

## After a Week

A week in vArranger2 is not a larger unlabeled style pile. It is the same title, a shorter live backing band, and a note that still makes sense before the next keyboard set. Take finished styles off the live set so the next visit starts on the gig desk that is still open.

## Sign-off

- [ ] The vArranger2 workspace name is short enough to scan
- [ ] Only live styles sit on the gig desk
- [ ] A second player can read the style handoff

## Field Note

vArranger2 is easier to trust when the gig desk stays smaller than the unlabeled style pile it came from. Name the file, keep the live backing band, finish one visible keyboard pass, and write what changed.
